# Аппаратный лифтинг лица в Самаре

Это публичная сборка для просмотра и согласования лендинга о четырёх методах аппаратного лифтинга: SMAS Ultraformer, игольчатый RF Secret, RF ReGen и Эндолифт.

Публичная версия размещается по адресу: https://espace-landing-pages.github.io/bormental-lifting/

Форма на лендинге демонстрационная: она проверяет заполнение полей в браузере, но не отправляет персональные данные и не устанавливает аналитические cookie. В сборку включены локальные страницы политики обработки персональных данных, согласия на обработку персональных данных и пользовательского соглашения.
