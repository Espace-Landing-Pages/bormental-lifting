# Аппаратный лифтинг лица в Самаре

Это публичная сборка для просмотра и согласования лендинга о четырёх методах аппаратного лифтинга: SMAS Ultraformer, игольчатый RF Secret, RF Duet V и Эндолифт.

Публичная версия размещается по адресу: https://espace-landing-pages.github.io/bormental-lifting/

GitHub Pages хранит общие файлы страницы, которые подгружаются в Tilda. На опубликованном лендинге Tilda кнопка в шапке «Заказать обратный звонок» открывает отдельную нативную форму с полями имени и телефона. Остальные CTA ведут в форму консультации. Публичные телефонные ссылки удалены; отправка заявок, аналитика и обработка согласий настраиваются в Tilda.
